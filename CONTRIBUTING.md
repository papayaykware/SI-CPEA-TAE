# Contribuir a SI–CPEA–TAE

Gracias por el interés. El proyecto prioriza claridad conceptual, reproducibilidad y crítica verificable.

## Antes de abrir una Issue

Incluye:
- pregunta concreta;
- hipótesis o componente afectado;
- evidencia o referencia;
- alternativa explicativa;
- posible criterio de falsación.

## Pull requests

1. Explica el problema y el cambio.
2. Mantén separadas hipótesis, inferencias y resultados.
3. No añadas DOI, benchmarks o resultados no verificados.
4. Incluye semillas, configuración y dependencias para experimentos.
5. Documenta resultados negativos y limitaciones.

## Principios

- No presentar simulaciones como evidencia sobre superinteligencias reales.
- No atribuir conciencia o benevolencia sin evidencia independiente.
- No reducir derechos o dignidad a una métrica compensable.
- No introducir capacidades autónomas con efectos externos en los experimentos iniciales.
