# Resultados

Los resultados se incorporarán únicamente después de ejecutar experimentos documentados.

Cada entrega deberá incluir:
- identificador del experimento;
- versión de código;
- configuración y semillas;
- datos o procedimiento de regeneración;
- métricas y análisis;
- resultados negativos;
- limitaciones y desviaciones del protocolo.

No se presentan resultados empíricos en la versión fundacional.
