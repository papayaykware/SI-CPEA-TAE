# Datos sintéticos

Este directorio se reserva para datos generados por experimentos.

No contiene datos humanos ni datasets empíricos en la versión fundacional.

Cada dataset futuro deberá acompañarse de:
- esquema y diccionario de variables;
- método de generación;
- semilla;
- licencia;
- checksum;
- limitaciones y usos permitidos.
